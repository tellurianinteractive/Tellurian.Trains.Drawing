# Sections

A module built in several parts is divided into sections by section joints. Sections don't have to be equally long. The table shows each section and its **length along the track**.

## Sections of the same length

- **Number of sections**: type how many sections the module has, and it is divided into that many sections of the same length along the track. On a curve they also have the same angle, and the same length along either edge. The joints there were are replaced.
- **Make equal** gives the sections the module has the same length again, e.g. after a joint was moved.

## A selected joint

Select a joint in the drawing to set its exact position:

- **Distance from the start along the track**: where the joint crosses the track, measured along the track from the module's first end.
- **Angle from the start of the curve**, on a curve module: where the joint crosses the track, as the angle from where the curve starts. The joint is at right angles to the track, so the angle is the same at the track and at both edges, and you can measure it on the real module.
- **Points**: the X and Y of each point of the joint, in millimetres. Type them, or drag the points in the drawing. Click the number to select a point.
- **Add point** adds a point after the selected one; move it to make the joint bend. **Delete point** removes the selected point. The ends stay on the module's edge.

Joints between sections always fit. End profiles are compared only where modules meet in a hall plan.
