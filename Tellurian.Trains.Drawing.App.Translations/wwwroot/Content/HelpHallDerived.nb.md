# Avledede egenskaper

Verdiene beregnes fra tegningen og endres mens du tegner; de kan ikke skrives inn.

- **Størrelse**: hallens bredde og dybde.
- **Gulvareal**: arealet innenfor veggene.
- **Brukbart gulvareal**: gulvarealet uten søyler, inventar, områdene som holdes frie foran dører, og sperrede områder.
- **Vegger**, **Hindringer**, **Dører og utganger** og **Sperrede områder**: hvor mange det er.
- **Modulinnganger**: dørene der moduler kan bæres inn og ut.
