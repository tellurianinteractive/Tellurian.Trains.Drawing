# Einstellungen

Deine Einstellungen werden in diesem Browser gespeichert, nie in Zeichnungsdateien.

- **Benutzername** wird im Änderungsverlauf der Zeichnungen eingetragen, die du speicherst.
- **Land** und **Maßstab** bestimmen, welche Normen und Endprofile angeboten werden.
- **API-Schlüssel für das Modulregister** ist für das Modulregister, wenn die App es verwendet.

## Deine Daten behalten

*Speicher in diesem Browser* zeigt, ob der Browser deine Einstellungen und Entwürfe behält und wie dein Browser sie behält. Exportiere deine Einstellungen in eine Datei und importiere sie wieder, wenn der Browser sie vergessen hat, oder in einem anderen Browser.
