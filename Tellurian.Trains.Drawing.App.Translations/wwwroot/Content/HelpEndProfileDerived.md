# Derived properties

These values are calculated from the drawing and change as you draw; they can't be typed.

- **End profile size**: the width and height.
- **Tracks** and **Track offsets**: how many tracks there are and their distances from the centre. **c/c** is the distance between neighbouring track centres.
- **Screw holes**: how many there are.
- **Symmetry**: whether the end profile is the same as its mirror image. If it isn't, it tells what differs: tracks, screw holes, ground line, outline or dowels.

An asymmetric end profile is mirrored at a module's end B, so that its high side stays on the same side of the track.
