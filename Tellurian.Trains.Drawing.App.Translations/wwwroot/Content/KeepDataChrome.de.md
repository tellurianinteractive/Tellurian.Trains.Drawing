# Deine Daten in Chrome behalten

Chrome behält deine Einstellungen und Entwürfe, außer es ist so eingestellt, dass es Websitedaten beim Schließen löscht. Wenn sie verschwinden:

1. Öffne **Einstellungen** im ⋮-Menü, wähle **Datenschutz und Sicherheit** und dann **Website-Einstellungen**.
2. Wähle unter **Zusätzliche Inhaltseinstellungen** den Punkt **Auf dem Gerät gespeicherte Websitedaten**.
3. Wenn **Daten löschen, die Websites auf deinem Gerät gespeichert haben, wenn du alle Fenster schließt** gewählt ist, klicke neben **Dürfen Daten auf deinem Gerät speichern** auf **Hinzufügen** und füge die Adresse dieser Website ein.
4. Wenn du den Modulzeichner über das Installationssymbol in der Adressleiste als App installierst, behält Chrome seine Daten zuverlässiger.

Alles in einem Inkognitofenster wird beim Schließen gelöscht.
