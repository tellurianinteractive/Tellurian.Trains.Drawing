# Behåll dina data i Chrome

Chrome behåller dina inställningar och utkast, om det inte är inställt på att radera webbplatsdata när det stängs. Om de försvinner:

1. Öppna **Inställningar** i ⋮-menyn, välj **Sekretess och säkerhet** och sedan **Webbplatsinställningar**.
2. Under **Fler innehållsinställningar**, välj **Webbplatsdata på enheten**.
3. Om **Radera data som webbplatser har sparat på enheten när du stänger alla fönster** är valt, klicka på **Lägg till** vid **Tillåts spara data på enheten** och klistra in den här webbplatsens adress.
4. Om du installerar Modulritaren som app, med installationsikonen i adressfältet, behåller Chrome dess data mer pålitligt.

Allt i ett inkognitofönster raderas när det stängs.
