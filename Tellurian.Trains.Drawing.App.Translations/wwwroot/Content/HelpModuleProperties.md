# Properties

Identify the module by its prefix and number, by a name, or by both.

- **Prefix** and **Number**, e.g. *SFjä 0012*: the letters the owner marks modules with, and the owner's number of the module. For a FREMO module they are the owner's FREMO prefix and the FREMO module number. A number needs the prefix.
- **Name**: needed when the module has no number.
- **Owners**: the names of the owners, separated by commas. An owner may be someone other than you. For a module in the Module Registry, the Registry's owners hold.
- **Package**: the box the module is transported in. Modules in the same box have the same label; they are submitted to a meeting together as one package. For a module in the Module Registry, the Registry's package holds.

The prefix and number, or else the name, are written on the module along the track, with the owners' names in smaller text under them. Problems are shown in red but don't stop you, so the fields can be filled in in any order. Changes can be undone.

The **Revision log** shows who saved the module, and when.
