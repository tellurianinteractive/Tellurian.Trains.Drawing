# Start

Here you begin new drawings and continue your work.

## Begin

- **Open…** opens drawing files: end profiles, modules and halls. They are plain JSON files, e.g. *Club hall.hall.json*.
- **New module…**, **New end profile…** and **New hall…** start a new drawing.

## Resume work

While you work, your drawings are saved in this browser as drafts. A draft with unsaved changes is marked; save it to a file to keep it. **Recent files** can be opened again; in some browsers you must pick the file again.

Drafts are work in progress. Your drawings are kept and shared as files.
