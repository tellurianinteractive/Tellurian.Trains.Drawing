# Behåll dina data i Firefox

Firefox behåller dina inställningar och utkast, om inte dess sekretessinställningar raderar dem när det stängs. Om de försvinner:

1. Öppna **Inställningar** i ☰-menyn och välj **Sekretess & säkerhet**.
2. Under **Kakor och webbplatsdata**, klicka på **Hantera undantag…**, klistra in den här webbplatsens adress, klicka på **Tillåt** (inte *Tillåt för session*) och sedan på **Spara ändringar**.
3. Under **Historik**: om Firefox är inställt på att **aldrig komma ihåg historik**, välj **Kom ihåg historik**. Med **anpassade inställningar för historik** och **Rensa historik när Firefox stängs** räcker undantaget i steg 2.
4. När Firefox frågar om webbplatsen får lagra data i beständig lagring, välj **Tillåt**.

Allt i ett privat fönster raderas när det stängs.
