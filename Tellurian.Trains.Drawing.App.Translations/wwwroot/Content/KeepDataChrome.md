# Keep your data in Chrome

Chrome keeps your settings and drafts unless it is set to delete site data when it closes. If they disappear:

1. Open **Settings** from the ⋮ menu, choose **Privacy and security** and then **Site settings**.
2. Under **Additional content settings**, choose **On-device site data**.
3. If **Delete data sites have saved to your device when you close all windows** is chosen, click **Add** next to **Allowed to save data on your device** and paste this site's address.
4. Installing Module Draw as an app, from the install icon in the address bar, makes Chrome keep its data more reliably.

Everything in an Incognito window is deleted when it closes.
