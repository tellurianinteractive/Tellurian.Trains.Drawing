# Deine Daten in Firefox behalten

Firefox behält deine Einstellungen und Entwürfe, außer seine Datenschutzeinstellungen löschen sie beim Schließen. Wenn sie verschwinden:

1. Öffne **Einstellungen** im ☰-Menü und wähle **Datenschutz & Sicherheit**.
2. Klicke unter **Cookies und Website-Daten** auf **Ausnahmen verwalten…**, füge die Adresse dieser Website ein, klicke auf **Erlauben** (nicht *Für diese Sitzung erlauben*) und dann auf **Änderungen speichern**.
3. Unter **Chronik**: Wenn Firefox die Chronik **niemals anlegen** soll, wähle **anlegen**. Mit **benutzerdefinierten Einstellungen** und **Die Chronik löschen, wenn Firefox geschlossen wird** genügt die Ausnahme aus Schritt 2.
4. Wenn Firefox fragt, ob diese Website Daten im dauerhaften Speicher ablegen darf, wähle **Erlauben**.

Alles in einem privaten Fenster wird beim Schließen gelöscht.
