# Why Module Draw?

Many modules and hall plans are drawn today in general CAD programs such as AutoCAD and SketchUp. They are excellent tools, but they were made for buildings and machine parts, not for model railway modules. Module Draw is made for exactly this one job.

## No licence, nothing to install

CAD programs cost money, often as a yearly subscription, and the free versions have limitations. Only a few in a module group have a licence, so the drawing ends up with them. Module Draw is free and runs in the browser on any computer. It works offline and can be installed as an app. Everyone can draw their own modules.

## It knows what a module is

To a CAD program a module is only lines and arcs. You must know the standard yourself and draw every detail correctly by hand. Module Draw knows the standards, such as FREMO and MMM, with their end profiles:

- A straight or curved module is created from a few measures: length, radius, angle and width.
- Every module end gets an end profile from the standard, with the tracks at the right positions.
- The module's designation, owners, sections, tracks and operation location are part of the drawing, not just text on it.
- You learn it in minutes, not in a course. No CAD skills are needed.

## Hall plans in minutes, not evenings

In CAD, a hall plan means copying module drawings into one file and moving and rotating each one by hand until the ends meet. Every change in the order means doing it again, and no one checks that the modules really fit together. In Module Draw:

- You import the modules for the meeting, e.g. from the Module Registry, and put them in order. Each module joins the previous one by itself.
- Turning a module around or changing the order takes one click; the rest of the line follows.
- The joints are checked against the end profiles and heights, and modules that overlap walls, pillars, emergency exits or each other are shown at once.
- Branches, loops, operator spaces, walking paths and duck-unders are part of the plan.
- You get printouts with dimensions for the people setting up the layout, and lists of modules and owners.

## Drawings that can be shared

Drawings are saved as open files that everyone can read with Module Draw, without a licence and without the right version of a CAD program. The same files are used by the Module Registry, so a module drawn once can be used in every hall plan, at every meeting.
