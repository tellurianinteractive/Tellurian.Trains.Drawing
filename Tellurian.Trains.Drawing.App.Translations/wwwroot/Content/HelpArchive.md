# Archive

The *Archive* pane shows the drawing's name and kind, the file it was opened from or last saved to, and whether the file has your latest changes.

## Buttons

- **Save** saves the drawing to its file; the first time, you choose where. Browsers that can't save in place, such as Firefox and Safari, show **Save (download)** instead: a new file is downloaded, and you choose the old file to replace it.
- **Save as…** saves the drawing to another file, and you continue in that file.
- **Save to my catalogue**, for end profiles, adds the end profile to your catalogue, so that your modules can use it.
- **Discard draft** removes the draft from this browser and goes back to the start page. The file is not affected. If there are unsaved changes, you are asked first.

## Drafts and files

While you work, every change is saved in this browser as a draft; the line at the bottom of the pane says when it is. A draft is work in progress: save the drawing to a file to keep it and to share it. *Unsaved changes* means that the file doesn't have your latest changes yet.

## End profiles in modules

A module file has its own copy of every end profile it uses, so that others can draw it. When you open a module and an end profile it uses has changed in your catalogue, the module gets the new version, and the pane tells which end profiles were updated. Save the module to keep them in its file.
